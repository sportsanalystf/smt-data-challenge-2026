1 On the Big Screen!

This project turns SMT player- and ball-tracking data into a real-time baseball storytelling engine: instead of showing raw statistics, it finds the interesting moments automatically, explains why they matter, and presents them in a form a fan understands in the seven seconds a scoreboard graphic is on screen.

Everything is built twice — once in R, once in Python — so each component can be read in whichever language the reader prefers, and so the two act as a cross-check on each other.

1.1 How the project is organised

Each component is a standalone module with a matching chapter in this book:

# Component R module Python module
1 Play-by-play from tracking R/R01_play_by_play.R components/c01_play_by_play.py
2 WPA & Leverage Index R/R02_wpa_leverage.R components/c02_wpa_leverage.py
3 Tracking features R/R03_tracking_features.R components/c03_tracking_features.py
4 Speed & baserunning R/R04_speed_baserunning.R components/c04_speed_baserunning.py
5 Power & hitting R/R05_power_hitting.R components/c05_power_hitting.py
6 Pitching R/R06_pitching.R components/c06_pitching.py
7 Defense & fielding R/R07_defense.R components/c07_defense.py
8 Fan-interactive games R/R08_fan_interactive.R components/c08_fan_interactive.py
9 Composite & storytelling R/R09_composite.R components/c09_composite.py
10 Play animation R/R10_animation.R components/c10_animation.py

The R modules extend the organizers’ own SMT_Data_Starter.R — its Arrow datasets, animate_play() and create_play_by_play() are used directly rather than reimplemented.

1.2 The dependency that shapes everything

The SMT tables record base occupancy but no outs, no count, and no score. Win probability, leverage and run expectancy are all functions of (inning, half, outs, base state, score differential), so none of them exist until game state is reconstructed. That is why Component 1 comes first: it is not bookkeeping, it is the foundation the entire engine stands on.

Component 1 validates against real baseball rates:

Quantity Reconstructed Real MiLB reference
Runs per game 10.12 ≈ 9.5
Hits per game 19.7 ≈ 18
Plate appearances per game 76.6 ≈ 76
Half-innings balancing to 3 outs 99.8 % 100 %

1.5 What is deliberately not modelled

Honesty about scope was treated as a feature of the submission:

  • Called strike probability — the data contains no umpire calls, so there is nothing to supervise. A calibrated geometric zone flag and a genuinely supervised P(ball in play | location) are provided instead.
  • Stolen-base / pickoff probability — no steal or pickoff outcome labels exist. Those products report measured lead distance and burst.
  • Spin rate — not recoverable from positional tracking. Pitch movement (deviation from a straight line, with gravity removed) is used instead.

## What is deliberately not modelled

Honesty about scope was treated as a feature of the submission:

- **Called strike probability** — the data contains no umpire calls, so there is
  nothing to supervise. A calibrated geometric zone flag and a genuinely
  supervised *P(ball in play | location)* are provided instead.
- **Stolen-base / pickoff probability** — no steal or pickoff outcome labels
  exist. Those products report *measured* lead distance and burst.
- **Spin rate** — not recoverable from positional tracking. Pitch *movement*
  (deviation from a straight line, with gravity removed) is used instead.
